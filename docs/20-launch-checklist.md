# Launch checklist (Phases 19–20)

The website must not be treated as launched until every item below is done.

## Content accuracy

- [ ] Full legal / professional name verified
- [ ] Biography rewritten with real background
- [ ] Location verified
- [ ] Email / phone / WhatsApp verified and tested
- [ ] Social links verified (only platforms actually used)
- [ ] Showreel URL + poster verified
- [ ] Event videos verified (titles, cities, years only if real)
- [ ] Gallery photographs verified (no AI imagery)
- [ ] Testimonials added only if client-approved — otherwise remain hidden
- [ ] All `[TO REPLACE]` and `[DEV PLACEHOLDER]` strings removed
- [ ] No fake metrics, awards, clients or counters

## Product / technical

- [ ] Custom domain connected (Vercel)
- [ ] HTTPS confirmed
- [ ] Favicon confirmed
- [ ] Metadata + Open Graph confirmed with real copy/image
- [ ] Sitemap + robots.txt live
- [ ] Privacy Policy reviewed
- [ ] Terms reviewed
- [ ] Booking form delivers email
- [ ] WhatsApp / Call / Email links tested on mobile
- [ ] 404 page checked
- [ ] Production build succeeds
- [ ] Lighthouse / performance pass on mobile
- [ ] Accessibility basics (keyboard, focus, contrast, alt text)
- [ ] No console errors on primary pages

## Design QA

- [ ] Desktop + tablet + mobile reviewed
- [ ] Host remains visual focus in hero once photo is added
- [ ] Motion respects `prefers-reduced-motion`
- [ ] No AI-slop patterns (purple gradients, pills, glass cards, fake social proof)
