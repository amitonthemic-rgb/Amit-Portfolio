# Phase 3 — Information Architecture

## Sitemap

| Route | Purpose |
|-------|---------|
| `/` | Primary conversion page — identity, presence, showreel, events, book |
| `/about` | Full biography, languages, style, location |
| `/showreel` | Primary showreel + supporting video gallery |
| `/events` | Event types hosted + capability narrative (no fake history) |
| `/gallery` | Editorial photo gallery |
| `/contact` | Booking form + WhatsApp / Call / Email |
| `/privacy` | Privacy policy for form data actually collected |
| `/terms` | Terms for site use and booking enquiries |
| `/404` | Branded not-found |

Optional later: `/press` — only when press assets exist.

## Primary user journey

1. Land on Home — understand who the host is
2. Absorb stage presence (hero photography / video)
3. Watch showreel
4. Explore event types & gallery
5. Read about / capabilities
6. Book via form / WhatsApp / call
